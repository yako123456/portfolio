W01

行ける駅を探すtrain-map

駅名と分数を入れると、その時間内に電車で行ける駅を地図に表示するWebアプリ。

  • 最短時間の探索を自作 優先度付きキュー（二分ヒープ）から書いたダイクストラ法で、首都圏1,708駅・1,975区間を探索
  • オープンデータから所要時間を推定 国土数値情報を加工するスクリプトを用意し、駅間の距離から各駅停車相当の時間を計算。地下鉄と山手線は別の速度で見積もり
  • 乗り換えと直通運転 乗り換えは1回5分を加算、直通運転は乗り換えに数えない
  • 自動デプロイ GitHub Actionsで、プッシュするたびにGitHub Pagesへ公開
  • TypeScript
  • Next.js
  • React
  • Leaflet
  • OpenStreetMap
  • Tailwind CSS
  • GitHub Actions

W02

落ち物ゲーotimono

落ちてくるノーツをキーボードで叩く、練習向けのリズムゲーム。

  • ライブラリなしでゲーム本体を実装 Canvasへの描画、キー入力、判定までを約900行のJavaScriptで作成
  • 細かく設定できる 使うキー、落下速度、間隔（ms / BPMと音符の種類）、同時押しの確率、判定タイミングの調整
  • 音もコードで鳴らす 効果音と手拍子はWeb Audio APIで生成。音声ファイルは使っていません
  • 結果をグラフで確認 クリア後に判定の内訳を表示。前回の設定はブラウザに保存
  • HTML
  • CSS
  • JavaScript
  • Canvas
  • Web Audio API
  • Chart.js
  • GitHub Pages

W03

見守りネットワークmimamori-demo

玄関の見守りを中心に、服薬・体調・予定・日誌・緊急連絡をひとつにまとめた介護支援Webアプリ。就職作品として制作。

  • 静かでやさしい見守り 本人には音を鳴らさず、家族にだけDiscordで知らせる設計
  • センサーからWebまで Raspberry Piの赤外線センサーとカメラで玄関付近の動きを検知し、写真つきで記録。通信が切れている間は保存して再送
  • 毎日の介護を記録 服薬の飲み忘れ通知、体温や血圧のグラフ、通院予定のお知らせ、家族で共有する日誌
  • 公開を前提にした作り 管理者と家族の権限分け、ログイン失敗の回数制限、自動テスト、誰でも試せるデモモード
  • Node.js
  • Express

  • Render
